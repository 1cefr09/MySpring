# MySpring

MySpring是笔者在学习Spring的过程中，为了更好的理解IOC而编写的一个简易的IOC框架。初步实现了IOC容器、DI、BeanPostProcessor。在IOC部分借鉴了Spring的三级缓存的思想，允许循环依赖，具体流程如下：

Bean初始化加载的流程为：

在AnnotationConfigApplicationContext的构造器中，首先会new一个BeanDefinitionReader（作为父类的属性）。BeanDefinitionReader中的registryBeanClasses是一个列表，存储扫描出来的bean的全类名。然后执行doScan将目标目录下的子目录和文件挨个扫描，将其类名加入registryBeanClasses。然后AnnotationConfigApplicationContext构造器中执行refresh（调用父类AbstractApplicationContext的）。

在AbstractApplicationContext中，定义了最主要的依赖注入的过程。在refresh中，首先会调用BeanDefinitionReader的loadBeanDefinitions方法，将registryBeanClasses中的类，创建为BeanDefinition（BeanName和FactoryBeanName），存入列表返回。接着将返回的beanDefinition列表注册。注册的流程：遍历beanDefinition列表，对于有@Component等注解的类，将其FactoryBeanName放到beanDefinitionMap中，后续取用。然后注册BeanPostProcessor，对于beanDefinition列表中的每一个，检查是否实现了BeanPostProcessor 接口，如果是就放到beanPostProcessors 列表中。最终进行Autowired。

Autowired流程：对于beanDefinitionMap中的BeanDefinition，逐个按照beanName调用getBean。getBean首先查找一级缓存，如果无，先判断是否正在创建这个bean，如果是，则说明存在循环依赖，先从二级缓存获取，如果二级缓存中不存在，就尝试从三级缓存中获取ObjectFactory对象，从中获取bean，放入二级缓存，从三级缓存中移除，返回bean。

如果三个缓存都没有，就正式开始创建Bean流程，将beanName放入当前正在创建的Bean名称集合，调用createBean后放入一级缓存，再从当前正在创建的Bean名称集合中移除。

createBean的流程：根据beanName和BeanDefinition，先实例化一个bean，再将其加入三级缓存，然后对其进行属性注入populateBean：先检查是不是Component注解下的，然后获取所有属性，遍历其中有Autowired注解的，获取其Type和Name。如果这个类是个接口，那么就去beanDefinitionMap中寻找这个接口的实现类且不是这个接口本身的Bean，然后如果找到的实现类多于1个，就根据Qualifier注解中的value，去getBean将其注入，若没有Qualifier就抛异常；反之实现类只有一个，就直接getBean将其注入。如果不是一个接口也可以直接getBean注入。

此时bean注入完成，正式初始化，执行BeanPostProcessor前后的内容。
